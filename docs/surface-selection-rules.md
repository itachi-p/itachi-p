## 判断基準（1問だけ）

**証拠がどこにあるか。**

| 証拠の所在 | 使うもの |
|---|---|
| リポジトリ内・ローカル実行結果（ビルド/型/ログ/curl） | ターミナル CLI |
| ブラウザ上の挙動・外部ダッシュボード（Vercel/Neon/Render/Supabase） | Desktop の Code タブ |
| 証拠は出揃っていて、必要なのは解釈・仕様判断 | Web版チャット |
| 左に開いている他人のページ、そのセッションで完結 | Claude in Chrome |

## 禁止事項

- 自作アプリの挙動確認に Claude in Chrome を使わない（→ Desktop の Code タブ）
- Claude in Chrome で文脈の引き継ぎを前提にした使い方をしない
- チャット用途で Desktop アプリを使わない（チャットは Web版か Chrome に固定）
- Desktop の Code セッションでコードを変更しない。確認と報告のみ
  （CLI → Desktop は `/desktop` で移行できるが、逆は不可。
   Desktop 側の文脈は CLI に持ち帰れない）

## サーフェスを跨ぐときに運ぶもの

セッションではなく **docs/ とコミット履歴** に載せる。
サーフェス間で人間が手で運ぶのは、次の2つだけに抑える。

- 何がどう壊れたか（エラー文言・再現手順、数行）
- 判断が変わった理由（→ decisions.md に書く）

これ以上を運ぼうとしている時点で、サーフェスの選択を間違えている。

## エスカレーション

Code が2回試して直らない、または原因が仕様の前提そのものに触れる場合のみ
Web版チャットへ。それ以外は Code 内で完結させる。
（前提に触れる問題を Code に投げても「指示通りに直す」方向にしか動かない）
